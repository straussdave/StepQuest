\section{Source Code Repository}

The source code of the StepQuest prototype is available in the following
GitHub repository:

\begin{center}
	\url{https://github.com/straussdave/StepQuest}
\end{center}

Release version 0.3.5 was used during the user study

\section{Android Application Package}

The APK used during the user study is available at:

\begin{center}
	\url{https://drive.google.com/file/d/1Pk4RrTVzy1FXJfj_MVrzTgyCyz_CZW8W/view}
\end{center}

The APK can be installed on compatible Android devices by downloading the file
and permitting installation from the application used to open it. The
prototype requires access to physical activity data for step counting.
